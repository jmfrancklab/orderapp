ReceiptSymbols.ttf contains only U+2713 (check) and U+2753 (question mark),
subset from NotoSansSymbols2-Regular.ttf (Google, SIL OFL 1.1; see LICENSE).
The font was renamed ReceiptSymbols after subsetting. It is bundled to keep
PDF annotation symbols identical on PythonAnywhere and local machines.

Source: https://github.com/notofonts/symbols
